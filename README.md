# توثيق Bootstrap بالعربية والإنجليزية

قارئ ثابت يعرض المقطع العربي إلى جانب المقطع الإنجليزي. يعرض دليل Bootstrap 5.3.8 فقط، مع الصفحة الرئيسية الرسمية والأمثلة وصفحات التنزيل والترحيل. الإصدارات الأخرى محذوفة من البناء، وبياناتها باقية في `content/` وتعود بإضافتها إلى `releases` في `scripts/common.mjs`.

## تشغيل الموقع

يتطلب التشغيل Node.js 22 أو أحدث. ملفات الموقع المبنية موجودة في `dist/`.

```sh
npm start
```

افتح `http://127.0.0.1:4173/`. للاستضافة الثابتة، انشر محتويات `dist/` في جذر النطاق.

## إعادة البناء والتحقق

```sh
npm ci
npm run build
npm run check
```

مع تشغيل الخادم، يقيس `npm test` المحاذاة على الديسكتوب والموبايل ويختبر البحث وتبديل الإصدار والنسخ والمعاينات وتسلسل القراءة. يشغّل `npm run test:audio` اختبارًا إضافيًا في Chrome بواجهة مرئية وأصوات عربية وإنجليزية مثبتة في النظام.

## مصادر المحتوى

- [حصر الصفحات](content/scope.json) يسجل خريطة الموقع، والروابط المكتشفة، ومعرّفات الإصدارات في المستودع الرسمي.
- [فهرس العناوين](content/sections.json) يسجل معرّفات الأقسام وترتيبها.
- [تقرير التغطية](content/coverage.json) يسجل عدد الصفحات المكتملة لكل إصدار، والمسارات التي أعادت 404، وروابط الأقسام التي غاب مرساها من الأصل.
- [قاموس النطق](content/glossary.json) يربط المصطلح الإنجليزي بنص النطق وتلميحه العربي.
- [إشعارات الترخيص](web/licenses/NOTICE.txt) تتضمن إسناد المحتوى والكود وتراخيصهما.

الترجمة العربية آلية مع مراجعة مختارة للعناوين والشرح الأساسي. يعتمد البناء على البيانات المحفوظة في `content/`. يستدعي `npm run inventory` و`npm run extract` المصادر الرسمية عند تحديث الحصر والمحتوى. يولّد `npm run translate` ترجمات للنصوص الجديدة، ويُدمج التصحيح التحريري من `content/reviewed.json` في البناء.

يستخدم الموقع Bootstrap وIBM Plex من روابط خارجية، وتستخدم المعاينات الإصدار الموافق للصفحة. يختار الاستماع من أصوات المتصفح عبر `speechSynthesis`.
