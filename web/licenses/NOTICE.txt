Bootstrap bilingual documentation reader
قارئ توثيق Bootstrap بالعربية والإنجليزية

Original documentation and examples by the Bootstrap team and contributors.
Original site: https://getbootstrap.com/
Original source: https://github.com/twbs/bootstrap
Each reader page links to the original version of that page.

Adaptations include the Arabic translation, parallel presentation, navigation,
search, pronunciation aids, and packaging of interactive examples.
